# Documentation archive

This directory is reserved for historical material that is intentionally kept in
Git: superseded contracts, dated evidence, migration notes, or decision records.

Archive documents are not current runtime contracts. A canonical document under
`docs/` must link to an archive item explicitly before it can be used as context
for current implementation work.

Uncommitted work briefs, raw audit matrices, and local research backlogs belong
under the ignored `experiments/spikes/` quarantine instead of this directory.
