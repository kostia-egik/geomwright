# Geomwright — русская документация

[English](../en/README.md) · [Все контракты](../README.md) · [Проект](../../README.md)

Geomwright локально автоматизирует КОМПАС-3D через MCP-сервер для AI-агентов и
браузерную Studio для оператора. Поддерживаются чтение моделей, ограниченные
изменения, отдельные параметрические семейства, спецификации и перепривязка
компонентов сборок. Это независимый проект, не связанный с АСКОН.

Версия 0.1.0 — alpha. Наиболее зрелые контракты относятся к работе с документами,
спецификациям и перепривязке. Запись эскизов, генераторы деталей и Studio
экспериментальны: сохранённый результат живой проверки подтверждает конкретный
случай, а не все сочетания параметров. Preview не является расчётом прочности
или подтверждением пригодности к изготовлению.

## Первый workflow с моделью

1. Запустите видимый КОМПАС и настройте интерпретатор bridge по инструкции установки.
2. Получите инструменты через `get_mcp_tool_catalog`; прочитайте `get_session_state`
   и `list_documents`, затем выберите явный `document_id`.
3. Прочитайте целевой объект, выполните preview/preflight операции.
4. Выполните поддержанную запись, проверьте readback и исправьте неуспешный результат.
5. Сохраните и переоткройте модель, если контракт семейства требует проверки сохранения.

Для эскизов используйте `inspect_sketch_full`. Для готовых тел начните с
`list_model_bodies`; после перестроения или переоткрытия получите селекторы заново.
Перед созданием детали генератором прочитайте контракт семейства.
