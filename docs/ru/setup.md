# Установка и запуск Geomwright

[English](../en/setup.md) · [Русский индекс](README.md) · [Основной README](../../README.md)

## Требования

Нужны Windows, КОМПАС-3D v23 и Python 3.11 или новее. Для MCP нужен совместимый
клиент; для Studio дополнительно устанавливается группа зависимостей `ui`.
Пакет имеет статус alpha и сейчас использует `mcp>=1.27,<2`.

Выполните в PowerShell из каталога клона:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[ui]" pywin32
$env:KOMPAS_PYTHON = (Resolve-Path .\.venv\Scripts\python.exe).Path
$env:KOMPAS_REQUIRE_VISIBLE = "1"
```

Для одного MCP замените `".[ui]"` на `.`. Host и bridge могут использовать разные
интерпретаторы: `KOMPAS_PYTHON` должен указывать на современный Windows Python
с `pywin32`. Старый встроенный Python 3.2 не понимает синтаксис текущего bridge.
Для переносимой установки задайте путь явно. Приоритет: аргумент конструктора,
`KOMPAS_PYTHON`, существующий проектный `.venv/cad-bridge/Scripts/python.exe`,
затем SDK fallback КОМПАС. Последний может быть слишком старым; неверная явная
настройка не заменяется другим интерпретатором молча.

Перед запуском production bridge выполняется compile/import preflight без COM,
ограниченный пятью секундами. Кешируется только успешная проверка; изменение
сигнатур файлов интерпретатора/bridge/runtime сбрасывает кеш. Локальный отказ
`CAD_RUNTIME_INVALID` сам по себе не блокирует CAD-сессию. Пользовательские bridge-
скрипты сохраняют собственный контракт исполнения.

Сначала откройте КОМПАС и оставьте его видимым. `KOMPAS_REQUIRE_VISIBLE=1`
переводит MCP в режим подключения к этому экземпляру; Studio всегда требует
видимую сессию для CAD-заданий. Расчёт preview не требует COM.

## Studio

Окружение, записанное только в конфигурации MCP-клиента, не передаётся отдельно
запущенной Studio. Задайте `KOMPAS_PYTHON` в её терминале/службе запуска либо
используйте проектный CAD-venv выше. Код выбора runtime входит в fingerprint
Studio вместе с выбранным путём интерпретатора: после изменения runner-кода или
окружения запуска старый сервер не переиспользуется.

В терминале под вашим управлением используйте `start-geomwright-studio.cmd` или:

```powershell
.\.venv\Scripts\python.exe -m geomwright.studio --port 8765
```

Для агента или фонового запуска:

```powershell
.\.venv\Scripts\python.exe -m geomwright.studio --background --no-browser --startup-timeout 15
```

Фоновый launcher проверяет `/health`, возвращает URL/PID и по умолчанию пишет
логи в `%LOCALAPPDATA%\Geomwright\studio` (переопределение — `--log-dir`).
Адрес по умолчанию: `http://127.0.0.1:8765`. При ошибке запуска прочитайте
указанный stderr-лог. Не запускайте Studio через PowerShell `Start-Process`
агентского терминала и не оборачивайте постоянный сервер в `scripts/run_bounded.py`.

## MCP

Настройте клиент на запуск Python из клона с `-m geomwright` через stdio.
[opencode.example.json](../../opencode.example.json) показывает конфигурацию
локального сервера OpenCode: замените пути-заглушки и сохраните обе переменные
в `environment`. У других клиентов названия полей могут отличаться.
Машинную конфигурацию храните локально. Stdio-сервер ждёт подключения клиента;
браузерной страницы у него нет.

После подключения вызовите `get_mcp_tool_catalog`, `get_session_state` и
`list_documents`. Перед работой с моделью явно выберите документ.
Старые CLI/import aliases сохранены; новые интеграции используют `geomwright`
и `geomwright.kompas`. Исследовательские инструменты включаются явно через
`GEOMWRIGHT_ENABLE_RESEARCH_TOOLS=1` до запуска сервера.

## Диагностика

| Симптом | Что проверить |
| --- | --- |
| Нет bridge Python, `SyntaxError` или `CAD_RUNTIME_INVALID` | Абсолютный путь `KOMPAS_PYTHON`, современный интерпретатор и `pywin32` в нём; preflight не обращается к CAD |
| Нет видимой сессии КОМПАС | Запустите v23 перед CAD-заданием; прочитайте состояние сессии |
| Не импортируется Studio | Установите `.[ui]` тем Python, которым запускаете Studio |
| Клиент использует старое окружение | Сохраните переменные в конфигурации клиента и перезапустите MCP-сервер |
| `CAD_BUSY` | Дождитесь завершения текущего вызова bridge; параллельные вызовы отклоняются |
| Timeout задания | Прочитайте checkpoint/логи и состояние документа перед повторной записью |

Ограниченные по времени проверки описаны в [руководстве разработчика](development.md),
задания, сохранение и закрытие — в [контракте Studio](../geomwright-studio.md) (EN).
