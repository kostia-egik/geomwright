# Examples

The JSON files and small Python programs in this directory are runnable examples
of the current host-side and MCP contracts. Start with the examples referenced
by the relevant document in [`docs/`](../docs/README.md).

Examples that create or inspect CAD documents need a local KOMPAS-3D v23
installation. They may write output files; point output to the ignored
`sample/generated/` directory or another disposable local directory.

Generated `.m3d` files and live readback evidence are intentionally not stored
in this repository. Historical probes and dated investigation scripts belong in
the local `experiments/spikes/` quarantine instead of being used as product
examples.
